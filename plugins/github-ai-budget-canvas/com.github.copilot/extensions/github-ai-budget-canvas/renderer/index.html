Safe assessment sequence

  1. Run Inventory for the active enterprise.
  2. Check prerequisites and confirm the snapshot matches the enterprise opened in the canvas.
  3. Review budget precedence, included usage, paid overage, exclusions, hard stops, and assignment data.
  4. Use the rules based or AI assessment to create recommendations from current evidence.
  5. Validate each action against current documentation and obtain approval before any write.
